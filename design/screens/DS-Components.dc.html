공통 컴포넌트

와이어프레임 전체에서 반복되는 UI를 컴포넌트로 묶었어요. 왼쪽은 이름·속성·크기·접근성 규칙, 오른쪽은 실제 모양과 변형이에요. 값은 '디자인 기준' 시트의 토큰을 따라요.

Button

<Button variant size icon disabled>

  • variant: primary · secondary · dark · text · emergency
  • size: md 56–60 (보호자) · lg 72–88 (당사자)
  • radius-md 16, 글자 heading 18 / 800
  • 한 화면에 primary는 1개
  • disabled: 점선 테두리 + surface-muted + text-tertiary, aria-disabled
  • 아이콘은 글자 앞 20–26px

Badge · StatusChip

<SignalBadge type> <StatusChip status>

  • SignalBadge: basic = 흰 바탕 + 1.5px 테두리 + 책 아이콘 / custom = 검정 바탕 + 연필 아이콘 / untrained = 점선 '연습 전'
  • StatusChip 높이 28, radius-full, small 13 / 800, 아이콘 14 + 글자
  • status: replied · delivered · unconfirmed · failed · waiting · connected · noReply
  • 전송(기기 전달)과 응답(터치)은 항상 다른 줄·다른 칩으로 표시
  • '읽음', '이해함' 표현 금지

RhythmGlyph

  • S(짧게) = 점, M(중간) = 짧은 선, L(길게) = 긴 선
  • size sm: 9 높이 / 점 9 · 중간 16 · 길게 26 / 간격 5
  • size md: 13 / 13 · 22 · 38 / 6
  • size lg: 20 / 20 · 34 · 58 / 10
  • 색은 currentColor (기본 #252525, 비활성 #5C5A54)
  • 재생 중: 지난 박자 진하게, 남은 박자 #8A867C
  • role=img + aria-label '길게 짧게 중간'

Navigation

<AppHeader> <TabBar active> <BottomSheet> <StickyAction>

  • AppHeader 높이 48: 왼쪽 뒤로(48), 가운데 제목 16·800, 오른쪽 닫기 또는 빈칸
  • TabBar 높이 84(하단 안전영역 22 포함), 5개: 홈·신호·위치·기록·설정. 현재 탭 = 노란 알약 52×30 + 800 + aria-current=page
  • StickyAction: TabBar 바로 위 고정, 위 1px 선, 배경 bg-ivory
  • BottomSheet: 상단 radius-xl, 손잡이 40×5, shadow-sheet
  • 당사자 앱에는 TabBar·헤더 없음
AppHeader 신호 추가 TabBar 홈 신호 위치 기록 설정

RecipientScreen

<RecipientScreen state>

  • 화면 전체가 버튼 1개 (분할·작은 버튼 없음)
  • state: idle · compose · sent · incoming · replied
  • 상태는 화면 전체 색 + 가운데 큰 도형으로 구분
  • 각 상태 aria-label에 보낸 사람·신호 이름·할 수 있는 동작 포함
  • idle 조작: 두 번 탭 = 보내기 화면, 3초 길게 = 도움 요청, 스크린리더 사용자 지정 동작 제공
  • sent·replied는 서버 확인 후에만 표시
